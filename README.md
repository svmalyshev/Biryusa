# Бирюса

Самостоятельный региональный проект, расположенный рядом с `Igarka/`.
Вход: `index.html`. Общей стартовой страницы нет.

Директории для будущих материалов:

- `data/` — реестр образцов и аналитические данные.
- `maps/` — карты и сведения о координатной привязке.
- `photos/` — фотографии обнажений и образцов.
- `thin_sections/` — микрофотографии шлифов.
- `assets/` — иллюстрации и подготовленные изображения для сайта.
- `scripts/` — обработка данных и сборка проекта.

Картографический шаблон заполнен: спутник Esri World Imagery (по умолчанию)
с переключением на Google в меню «Слои», четыре геологических слоя,
22 образца (21 место отбора) за 2024 и 2025 годы. Реестр дополнен по вкладке
`Biryusa` файла `../игарка_реестр.xlsx`: A — номер, B — координаты,
C — описание, D — сделано, E — план. Колонки G и I не используются.
Координаты и непустые описания реестра имеют приоритет над каталогами;
первоначальные сведения PDF сохранены в отдельном раскрывающемся блоке.
Пустые D/E не означают готовность; дополнительные анализы не выводятся
из примечаний и не наследуются другими образцами. BR24-02 и BR24-02/2 показаны
одним маркером с выбором образца. Фотографии и аналитические результаты
пока не подключены.

Символы пород заданы явно по номерам образцов: круг — все BR24 и
SM25-17, 18, 22, 26, 28, 29, 30, 33 (базитовые породы); ромб — SM25-19,
20, 24, 31 (метаморфические); треугольник — SM25-21, 25, 27, 32 (граниты);
квадрат — SM25-23 (песчаники шангулежской свиты, низы карагасской серии).
Цвет обозначает год отбора. Те же символы показаны в списке образцов;
сворачиваемая легенда «Породы» находится на карте.

Сборка: `scripts/build_biryusa.py` (Python с pdfplumber, openpyxl и Pillow).
Исходные данные сохранены отдельно в `03 - поля/2025_Бирюса/`.
Шаблон интерфейса: `scripts/portal_template.html`.
Данные: `data/samples.json`, `data/samples.csv`; каталоги-источники в `data/`.
Тайлы MBTiles экспортируются из TMS в XYZ; SQLite RMaps использует z=17-Z.
Для листов N-47-IX и N-47-XV веб-экспорт ограничен уровнем 14: дальнейшие
уровни исходной базы увеличивают объём без прироста детализации скана.
Слои без установленной привязки автоматически не накладываются.

Слой «N-47-XV_3g» получен из `Maps/Biryusa_2025_geotif.tif` по встроенной
привязке WGS 84 (EPSG:4326). `scripts/geotiff_layer.py` перепроецирует его
в XYZ-тайлы Web Mercator (EPSG:3857), уровни 8–14. Исходный TIFF не изменяется
и не копируется в сайт. Слой включён по умолчанию с прозрачностью 35%; эти
настройки можно менять на карте. Встроенная привязка использована как есть,
её точность по независимым наземным опорным точкам не проверялась.

Страница работает без сервера. Обе спутниковые подложки требуют интернет-соединения;
геологические карты и точки загружаются из локальных файлов.
Перед публикацией следует проверять состав материалов: исходные лабораторные
файлы и рабочие документы не обязательно предназначены для открытого доступа.
